# Keyboard shortcuts

`⌘` is `Ctrl` on Windows and Linux. The list matches `web/src/lib/shortcuts.ts`.

| Keys | Action |
|---|---|
| `Space` | Play / pause |
| `←` / `→` | Back / forward one frame |
| `⇧ ←` / `⇧ →` | Back / forward 1 second |
| `⌥ ←` / `⌥ →` | Nudge the selected caption ±30 ms |
| `S` | Split the selected clip or filter/effect clip (or captions, when none is selected) at the playhead |
| `M` | Merge the selected caption with the next |
| `Del` | Delete the selected clip, filter/effect clip or caption |
| `Esc` | Clear the selection |
| `⌘ S` | Save now (autosave runs every 5 s) |
| `⌘ Z` / `⇧ ⌘ Z` | Undo / redo |
| `1` – `9` | Switch tab: Media, Captions, Transitions, Effects, Filters, Templates (left pane), then Style, Display, Motion (right pane) |
| `⌘ K` | Unicode ⇄ FM converter |
| `?` | Show shortcuts |
| `⌘ scroll` | Zoom the timeline |
